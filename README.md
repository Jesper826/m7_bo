# M7 Bo

M7 Bo is een interactieve React-website die verschillende persoonlijke en visuele onderdelen combineert. De website bevat een introductie, een top 10-lijst, herbruikbare kaarten, een cookiecomponent en een interactieve kat.

Het project is gebouwd met React en Vite. De styling is verdeeld over verschillende CSS-bestanden per component.
